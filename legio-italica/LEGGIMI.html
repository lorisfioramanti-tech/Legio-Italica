Legio Italica: inizia da qui

Il sito è pronto per essere aperto sul tuo computer. Non devi installare nulla.

1. Apri il sito

Clicca qui per aprire Legio Italica. Oppure entra nella cartella dist e fai doppio clic su index.html.

Se parti dal file ZIP, clicca con il tasto destro e scegli Estrai tutto. Apri il sito dalla cartella estratta, non dall’anteprima dello ZIP. Mantieni insieme tutti i file e la cartella assets.

2. Cosa è già pronto

Home, Chi siamo, Legatus, Gradi, Membri, PvE/PvP, Eventi, Guide, menu per telefono e pulsanti collegati a Discord. Le guide si aprono premendo il titolo.

Il nome utilizzato è Koris, Gladiatore, con Cosmi come secondo Legatus. I gradi sono una proposta, l’elenco membri è da completare e non sono stati inventati eventi. Questa versione è un sito informativo: gli aggiornamenti ai contenuti si fanno nei file, senza pannello amministratore.

3. Pubblicalo gratis con GitHub Pages

Non è ancora online. GitHub Pages permette di pubblicare gratuitamente questo tipo di sito usando un archivio pubblico: tutti potranno vedere i file caricati. Non serve acquistare un dominio. Indicazioni verificate il 27 settembre 2026 nella guida ufficiale GitHub.

  1. Vai su github.com e crea un account gratuito, se non ne hai uno.
  2. Premi +, poi New repository. Un repository è la cartella online del sito. Chiamalo legio-italica, seleziona Public e crea il repository.
  3. Scegli uploading an existing file nella pagina iniziale, oppure Add file → Upload files.
  4. Apri sul computer la cartella dist. Trascina nella pagina GitHub il suo contenuto: index.html, style.css, app.js, config.js e la cartella assets. Non caricare la cartella dist intera: index.html deve essere direttamente nella cartella principale online.
  5. Premi Commit changes per salvare.
  6. Apri Settings → Pages. In Build and deployment, scegli Deploy from a branch. Seleziona main e /(root), poi Save.
  7. Attendi alcuni minuti e torna nella pagina Pages: troverai il collegamento pubblico, simile a https://tuonome.github.io/legio-italica/. Aprilo e prova il menu e Discord prima di condividerlo.

Per aggiornare il sito, sostituisci i file modificati con Add file → Upload files e salva di nuovo. Puoi chiedere qui le modifiche senza imparare a programmare.
